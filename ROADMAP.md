# Objetivo del proyecto

Desarrollar un sistema de punto de venta moderno, rápido, intuitivo y 100% funcional para la administración de Abarrotes Rosita-Andrea (WI).

El sistema funcionará sin conexión a Internet y permitirá controlar ventas, inventario, compras, proveedores y reportes.

# Filosofía del proyecto

RositaPOS no será un sistema genérico.

Será un software desarrollado específicamente para Abarrotes Rosita-Andrea (WI), pensado para trabajar de forma rápida, sencilla y confiable.

Cada nueva función deberá responder a una pregunta:

**¿Hace más fácil el trabajo en la tienda?**

Si la respuesta es sí, se implementará.
